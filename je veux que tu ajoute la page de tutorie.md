Configuration d'une nouvelle école
dans cette vidéo nous allons voir coment ajouter une nouvelle école dans l'application Kelasi
Procédure  
- Cliquer sur nouvelle école
- Remplir le formulaire avec les information de l'école en cliser sur enregistrer
- Ajouter les options et les classe puis importer les liste des élève par classe depui un fichier excel ou docx(fichier word)
NB: les colonne requi sont : Noms | sexe ou Nom | postnom | prenom | sexe
- Fixer les frais par trimestre et/ou par mois pour chaque classe ou par goupe de classe ou encore pas option
- Ajouter les rubrique poue la ventilation (facultatif)
